## Pitfalls

- [2026-11-22] 固定比例装饰图硬拉全屏=变形/裁花——满屏装饰用「四角取材+mask 羽化」自适应;
  暗色下角花图必须 brightness(.42)+sepia(.3)+hue-rotate(48deg),只压亮度会成白雾块
- [2026-11-22] corepack enable 会往仓库 package.json 写 packageManager 字段(踩后 git restore,
  用 COREPACK_ENABLE_AUTO_PIN=0 避);pnpm12 是启动器,首跑从 GitHub 拉 @pnpm/exe 原生二进制
  (直连间歇会挂)→用户级 .npmrc 指 npmmirror 后通;pnpm.cmd shim 用 Write 工具写,
  printf 的 \n 会吃掉路径里的 \nodejs
- [2026-11-22] bash 管道吞退出码复踩:后台命令必须 `| tail -N; exit ${PIPESTATUS[0]}` 且仍要读
  日志核对——AGP 中文路径报 BUILD FAILED 时 exit 0 骗过一次
- [2026-11-22] 微信原图缓存会被清理,收到素材第一时间拷进工作区(本次已拷,frame-green 等)
- [2026-11-22] winget --disable-interactivity 装 AS=假成功(无 UAC→无文件无注册项但退出码 0),
  重装必须让 UAC 弹窗被用户点「是」
