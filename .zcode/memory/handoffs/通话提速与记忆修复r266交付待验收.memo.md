## Decisions

- [2026-11-14] 通话速度优先:工具全清只留挂断,记忆工具保留;如需个别工具(如 music_control)通话可用,等用户验收后做白名单
- [2026-11-14] 通话轮生成失败不落错误卡不锁队列——自动重试兜底,重试成功后错误卡只会像坏了
- [2026-11-14] 心里话回归开关门控(修工具越权),开关 UI 已补回 AssistantLocalToolPage
- [2026-11-14] 思考按钮常驻,不看模型 REASONING 标(自定义模型没打标也能调)

## Pitfalls

- [2026-11-14] PointerInputChange 无 isCancelled(当前 androidx 已移除)——取消检测用成员 isConsumed;awaitFirstDown 在 foundation.gestures;changedToUp 是 ui.input.pointer 扩展函数(r262 编译失败根因,CI 兜住)
- [2026-11-14] 通话链路(TTS 朗读源/字幕/收纳卡全文)不走普通消息的标记处理管线,<split/> 会裸露并被逐句朗读——必须 stripChatControlMarkers(BubbleSplitter,同包直接用 WAKE_TAG)
- [2026-11-14] 记忆 prompt 只注入索引,内容靠工具主动召回——裁工具时记忆工具必须保留,否则通话失忆
- [2026-11-14] gh run watch 经管道会吞退出码(误报成功),也可能被网络抖动打断(误报失败)——轮询 `gh run view --json status,conclusion` 最稳;CI 失败的 run 也占号,产物可能跳号
- [2026-11-14] MiMo voicedesign 每次请求现编音色(固定描述也漂移男女切换)——要稳定音色就留空描述用内置音色
