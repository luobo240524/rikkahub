## Pitfalls

- [2026-11-10] speech 模块 internal fun 跨 Gradle 模块不可见(pcmToWav 改 public 顶层函数)
- [2026-11-10] StrokeCap 在 androidx.compose.ui.graphics 不在 drawscope(四期教训第三次踩)
- [2026-11-10] Compose DrawScope.drawArc 没有 centerX/centerY/radius 形参,只有 topLeft(Offset)
  +size(Size) 形式;drawCircle 才有 center+radius
- [2026-11-10] buildJsonObject 里 put(String,Boolean/Int) 需要 import kotlinx.serialization.json.put
- [2026-11-10] REST 推送四坑:gh api 大 base64 超 Windows 32KB 参数上限→--input 文件传 JSON;
  -p parents=xxx 传成字符串→commit 变孤儿(parents:[])→必须 --input 传 {"parents":["sha"]};
  更新 ref 必须 -X PATCH(带 -f 默认 POST);同树兄弟 commit PATCH 会 422→force=true 安全(树相同)
- [2026-11-10] git fetch/git push 直连断了不一定一直断:本窗口 push 第 8 次成功、fetch 12 次全败——
  推送断连先挂后台重试循环(45-60s 步进),别急着只走 REST
- [2026-11-10] heredoc+sed 拼多行 commit message 会炸(unterminated s);单行 message 直接
  tr -d '\r\n' 最稳
- [2026-11-10] bash 管道吞退出码:`git fetch ... | tail -1 && echo OK` 永远 OK——判断成败必须
  用管道外退出码
