## Decisions

- [2026-11-07] **助手后台只互动不进聊天** — 用户未答按推荐落地:社交通知轮 requireVisibleReply=false,
  提示词明确"不需要时保持安静";聊天区不被打扰
- [2026-11-07] **双向互动** — 用户也能给助手的朋友圈/打卡点赞评论;评论助手内容会后台提醒助手,点赞不提醒(防噪音)
- [2026-11-07] **凡 UI 改动先出 HTML 预览再写代码** — 用户重申并升级为硬规则(本窗口两次迭代都先预览了)
- [2026-11-08] **心里话便签定稿方案A双列瀑布** — B 单列流被否;纸色随主题是用户点名的"和打卡一样的绿色系"
- [2026-11-08] **称呼不预设** — 提示词不写死昵称,NAMING_GUIDE 让助手用自己平时对TA的称呼
- [2026-11-08] **主题切换器=折叠下拉** — 用户点名"主题折叠下拉"(收纳原则),各页顶栏 🎨

## Pitfalls

- [2026-11-07] **const val 初始化器禁止前向引用** — AUTONOMOUS_WAKE_PROMPT 引用后声明的
  NAMING_GUIDE 报"must be initialized";const 常量声明必须放在引用它的 const 字符串之前
- [2026-11-08] **顶层 const 不能用「文件名.属性」寻址** — `me...service.WakeProtocol.NAMING_GUIDE`
  报 Unresolved(WakeProtocolKt facade 不可这样写);跨包用 `import me...service.NAMING_GUIDE` 直引
- [2026-11-07] **matchParentSize 不是顶层 import** — 它是 BoxScope 成员;顶层导入直接 Unresolved
  (两个窗口两次踩),Box 直接子项删 import 即可
- [2026-11-07] **HugeIcons 图标必须 HugeIcons.前缀+对象导入** — 裸名报 receiver mismatch(第二次踩)
- [2026-11-07] **joinToString 非内联** — transform 里不能调 @Composable,先 map 出结果
- [2026-11-08] **Actions run_number 会跳号** — 成功 run 42442649272 产物叫 r204(无 r203),交付别按 run 顺序想当然,以 release 资产名为准
- [2026-11-08] **Settings03 glyph 视口留白** — 图标显小不一定是容器小,换图标(Settings02)才是正解
- [2026-11-07] github 直连断连高频:后台循环重试有效;REST API 兜底(blob→tree→commit→ref)已验证可用;
  后台循环误报失败时先核 remote ref 再动(曾白建 orphan commit)
