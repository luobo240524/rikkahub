## Pitfalls

- [2026-11-23] **assistantId 是 Uuid 不是 String**:三处踩(ChatService granary/WorldPage
  bridge/LocalTools 注册),全部需 .toString();报 ARGUMENT_TYPE_MISMATCH
- [2026-11-23] **Tool.execute 必须返回 List<UIMessagePart>**:结果包
  listOf(UIMessagePart.Text(text));return@withContext 的 String 也要在外层包
- [2026-11-23] **const val 不能嵌跨包模板引用**:`const val P="...${me.x.Y}..."` 编译不过,
  改 private val
- [2026-11-23] **HONOR USB 无 ADB 接口**:Windows PnP 只见 MTP+HDB(报错)时=ADB 功能没
  暴露;开关关再开+仅充电↔传输文件切一次强制重枚举;仍不行走无线调试(pair 码+mDNS 拿端口)
- [2026-11-23] **pair 端口/码随弹窗失效**:protocol fault=对话框已关,重开拿新的秒配
- [2026-11-23] **npmmirror tarball 是 302**:curl 必须 -L;node(Windows)与 git-bash /tmp
  路径不通,脚本用相对路径
- [2026-11-23] **dist 包非 debuggable**:BuildConfig.DEBUG=false→WebView 调试不生效(无
  chrome inspect);页面 console 走 logcat `WebView` 标签;要 inspect 用本地 debug 变体
- [2026-11-23] **keystore.properties 的 storeFile 相对 app/ 目录**:写
  ../keystore/debug.keystore,否则 validateSigningDist 失败
- [2026-11-23] **管道吞退出码复踩**:gradle 输出 |tail 后 EXIT=0 假象,以日志 BUILD 行为准;
  含中文日志 grep 用 -a
