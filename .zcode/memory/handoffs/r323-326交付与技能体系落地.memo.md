## Decisions

- [2026-11-21] **编辑思考内容守卫放宽(用户拍板)** — 忽略工具部件,恰一个无签名思考块即可编辑;
  metadata 签名块(Claude/Gemini/OpenAI)不可编辑的官方守卫保留
- [2026-11-21] **自评协议转纯后台,⚠️观测脉冲保留不动(用户拍板)** — 语义层数据源=VitalsFallbackAnalyzer
  (快速小模型每轮);内心世界 inner_voice 的扩展点随之从主协议转向兜底分析器 prompt
  (即 r281 快照「小模型兜底同步扩」路径)
- [2026-11-21] **思考链静默化裸词口径(用户实拍驱动)** — 开唤醒助手思考里凡含 唤醒/wake 整句删、
  开表情包凡含 表情包/send_sticker 整句删;误伤自然考量的代价用户接受
- [2026-11-21] **顶栏角标定宽不占满(用户拍板)** — 8 字槽,标题吃剩余;分配反转机制见 Pitfalls
- [2026-11-21] **参数级小改动免预览(用户明示,硬规则修订)** — 限宽/间距/颜色/对齐直接改,不做预览;
  新页面/新交互/整体视觉方案仍先预览;已写入 ui-preview 技能与跨窗口记忆
- [2026-11-21] **「你的世界」技术路线(探讨定调,未动工)** — 否决 MCP 与网页端核心化;内置数据层+
  本地工具+唤醒轮+WebView 场景;动工从碎碎念+留灯起步;留灯=定向留言条带未读态(≈secrets 扩列)
- [2026-11-21] **rootcause 规则落地** — 同一问题补丁两轮不收敛→停手,列结构性方案(含行为影响)等
  用户拍板,禁第三轮同层补丁(思维链打地鼠五连教训)

## Pitfalls

- [2026-11-21] **权重配额叠加内部限宽=双重压缩**(r326 根因)——外层 weight(2f,fill=false) 在窄屏
  把 80dp 限宽的角标压到 4-5 字;UI 宽度分配先想「谁先量、谁吃剩余」:无权重子项第一轮先量,
  加权子项第二轮吃剩余(fill=false 留死空间,fill=true 恒占配额)
- [2026-11-21] **Kotlin 局部变量先声明后使用**(r323 踩:横幅引用下方声明的 remember 变量)——
  Compose 块内声明顺序即使用顺序;已入 ui-impl 清单
- [2026-11-21] **IAB 截图超高页 clip 平铺伪影**——760x1560 视口+clip 出双列重影;重设小视口
  (720x780)整页截才正常;与「fullPage 超高页平铺错乱」同族,案例如实记录
- [2026-11-21] **发送按钮显隐受 AnimatedVisibility(recordingVoice||asrState.isRecording) 门控**——
  ASR 录音态卡死=按钮无声消失(r322 静默化副作用:错误不弹了,卡死没人收尸);自愈拟案
  (超时无输入自动 stop/编辑模式常显)未实施,用户观察复现中
- [2026-11-21] **回退低版本被 Android 拦**——versionCode=run_number(r204 起)后回退=真降级
  (INSTALL_FAILED_VERSION_DOWNGRADE),非 app 加限制;回退路径=adb install -r -d(保数据)或
  卸载+WebDAV 备份恢复(有损耗)
