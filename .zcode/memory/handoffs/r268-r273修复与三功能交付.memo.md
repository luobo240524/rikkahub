## Pitfalls

- [2026-11-15] WebDavBackupItem 字段是 displayName 不是 name(CI 自检步兜住)——用外部类型字段前先读 data class
- [2026-11-15] sealed class 新增成员必须 grep 全部穷尽 when:TTSProviderSetting=TTSManager×2/
  SettingSpeechPage×1/TTSProviderConfigure×4+Types 注册;本次零遗漏靠全量 grep 封闭影响面
- [2026-11-15] 用户发来的导出文件先验归属:文件里头像/路径的包名(.debug=X 后缀)——自称"官方版"
  的 settings.json 实为 X 备份,包名一验便知,防止错误结论
- [2026-11-15] Room 手写迁移 SQL 不能带 DEFAULT 子句(除非实体 @ColumnInfo(defaultValue)),
  否则 schema 校验不匹配启动即崩;本次 anniversaries 按实体无默认值写裸 SQL
- [2026-11-15] Koin 位置参数注册(LocalTools get()×16)加参数=加一个 get(),顺序必须与构造器对齐
