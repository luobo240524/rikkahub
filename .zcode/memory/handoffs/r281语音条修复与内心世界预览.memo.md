## Pitfalls

- [2026-11-15] **fillMaxWidth 子项会把 wrap-content 父 Column 撑满整行**,兄弟 intrinsic 内容被按
  Start 挤偏——对齐丢失类 UI bug 新根因模式(r281);排查对齐问题先查中间包裹层有无满宽子项
- [2026-11-18] **::visualize 内联卡片同样要首行 meta charset + 引用路径用正斜杠**——宿主无 charset
  线索按 1252 解码中文全乱码;本地经带 charset 头的服务器测试看不出,内联宿主才暴露
- [2026-11-18] 弹层/菜单 popover 必须实底:半透明主题卡(星空 cardBg=7%白)做底会透视下层;主题需同时
  出 card(可半透明)与 card-solid(实底)两套
- [2026-11-18] 同一坐标换算双轨拆开:SVG 几何属性吃 viewBox 数值,HTML 覆盖层吃百分比;'百分比'+'px'
  拼接是静默失效(left 非法被忽略,元素落到流位置被裁)
