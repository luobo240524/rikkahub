## Decisions

- [2026-11-11] 收纳卡=主题色便签/记事本风(用户睡前拍板免预览,直接构建)
- [2026-11-11] 挂断告知只给事实不预设回应内容(用户明确);同时授权 TA 主动拨打(voice_call_ring
  措辞改明确授权)+主动挂断(hang_up_call)
- [2026-11-11] 通话跳过思考默认开(用户:"通话时思考不开没事")
- [2026-11-11] 静默提醒:满1h无新消息后台提醒,时长可累计(每小时一次),夜间23:00-9:00不生效;
  提示词禁用「用户」二字,用 TA/代词
- [2026-11-11] 九期边界建议(待用户确认):共同阅读一期 TXT/EPUB 先行(PDF 二期);一起听一期
  本地播放器+TA工具权限,网易云登录作为可选源(VIP/版权/接口稳定性风险须先告知)

## Pitfalls

- [2026-11-11] 密封类(AppEvent)加成员→所有穷尽 when 编译失败(RouteActivity 兜出);加分支
  `is AppEvent.X -> Unit`
- [2026-11-11] CustomTtsState 包装层 speak 参数名是 flushCalled(转发 TtsController.speak),
  不是 flush——命名不一致两套口径
- [2026-11-11] UIMessage.createdAt 是 kotlinx.datetime.LocalDateTime,进 java.time API
  (Duration.between/atZone)必须先 toJavaLocalDateTime(项目先例 ChatMessageActions.kt)
- [2026-11-11] Compose 之外:HTML 预览里 hidden 属性被自定义 display:flex 盖掉导致"点收起无
  反应",须补 [hidden]{display:none}
- [2026-11-11] 自查漏网之鱼仍会发生(VoiceCallVM 缺 contentOrNull import)——CI 自检步是最后
  防线,兜出成本低(2.5min),别省
