## Decisions

- [2026-11-08] 语音通话=每助手开关(voiceCallEnabled,默认关):门控发现页入口+主动来电工具注入
- [2026-11-08] 通话入口在发现页不占顶栏;独立路由 Screen.VoiceCall→ui/pages/call/VoiceCallPage+VM;
  会话挑选复用社交策略(lastConversationId→当前助手最近会话)
- [2026-11-08] 主动来电 v1=高优通知响铃(复用 CHAT_COMPLETED 渠道),接听路径=通知→app→发现→语音通话;
  提示词写明一天最多一两次
- [2026-11-08] 语音条 v1 不转文字(录音只存文件助手看不到);通话无静音/免提(控制器无暂停接口);
  节点提醒 v1=列表高亮+红点,无系统推送——均为已声明边界,后续可加
- [2026-11-08] 时间轴"串联动态"不落新表:页面层聚合 moments/checkins/secrets 按日展示(纯读免同步)

## Pitfalls

- [2026-11-08] HugeIcons object 访问仅限对象内置子集(Mic01/Play/Pause/Voice/Calendar03/ArrowLeft01/
  Add01 全踩):新图标一律双 import(import HugeIcons + import me.rerere.hugeicons.stroke.X,写 HugeIcons.X)
- [2026-11-08] Offset 在 androidx.compose.ui.geometry,不在 ui.graphics
- [2026-11-08] runCatching 是 stdlib,import kotlinx.coroutines.runCatching 必编不过(TimelineVM/VoiceCallVM 两处);
  runCatching{} lambda 无 it(receiver 写法)
- [2026-11-08] AppDatabase 加 abstract DAO 漏 import→KSP MissingType PROCESSING_ERROR
- [2026-11-08] ChatPage 顶栏 actions 是独立作用域,拿不到外层 vm/setting——新顶栏入口要么传参要么放组件外
- [2026-11-08] Edit replace_all 缩进陷阱:同模式调用点缩进不同只命中一处,自查必须 grep -c 核数
- [2026-11-08] 预览 HTML 必须首行 meta charset(否则浏览器按 1252 解码中文乱码);
  ::visualize 引用 JSON 路径用正斜杠(反斜杠未转义=宿主解析失败不内联)
