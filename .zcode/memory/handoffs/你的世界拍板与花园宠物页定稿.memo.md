## Pitfalls

- [2026-11-22] **JS 引用不存在的 id → 整脚本中断**(pet-v1 petcard 无 id,后面的
  renderChips/renderLog/applyWall 全没跑)——新文件自查要查 getElementById 目标存在
- [2026-11-22] **HTML 闭合缺失 → 物种卡嵌进 flex 行**(pet-v4 蛋卡少一个 </div>,
  后续卡片全嵌进蛋卡 flex 行被挤成竖条);根因=字符串拼 HTML 少闭合;教训=
  **新弹层/新布局必须截图过一眼**,嵌套结构 probe children 数
- [2026-11-22] **paintActive(el,scale) 的 scale 没人传 → NaN 尺寸**——参数级默认
  化在函数内部做,别指望每个调用点记得传
- [2026-11-22] **IAB 标签页经常释放/关闭**(markDeliverable 后、超时后均会消失);
  恢复=tabs.list → user.openTabs → user.claimTab;locator actionability 频繁超时
  时改用 evaluate 里 element.click() 绕过
- [2026-11-22] **IAB 截图三坑叠加**:整页 clip 平铺伪影(重设小视口+整页截可解)/
  渲染滞后(DOM 对但截图旧,等 600-800ms 补截)/临时改 CSS 解滚动会污染渲染层
  (改完必须还原+reload)
- [2026-11-22] **gh api 拉二进制**:contents .content+base64 对大文件为空;用
  `-H "Accept: application/vnd.github.raw"` 直取;勿 `export GH_TOKEN=$(grep...)`
  覆盖真实环境变量(本窗口踩过,空值导致 gh 报未登录)
- [2026-11-22] itch.io 本网络不可达(connect timeout);raw.githubusercontent 间歇
  断(SSL 35)——GitHub 素材统一走 gh api raw 头
- [2026-11-22] 设计模式会把属性面板改动直写本地 HTML——**编辑记忆文件/页面文件
  前先重读**(本窗口 wc 行数核对过未被改)
