# 决策

- [2026-11-01] **生图功能停用,事故以"日常可用"结案** — 用户明确不再用生图;r176/r177 生图修复在库但未实测,重启生图前必须先用 gpt-image-2 试一张验证
- [2026-11-01] **每完成一段工作立即 commit+push** — 用户要求跨设备信息不断层,云端仓库是唯一载体(长期有效的工作指令)
- [2026-11-01] **构建完成后给实测过的最快下载链接(纯文本格式)** — 用户网络 GitHub 直连慢,镜像时效性强,每次现测现推
- [2026-11-02] **气泡样式精简拍板** — 删"玻璃风格"选择器只留"气泡材质";材质只留 默认/玻璃/水珠(磨砂/毛玻璃肉眼无差);气泡形状移入助手页每助手独立,全局页删选择器
- [2026-11-02] **气泡美化走边框贴纸方向,不改形状** — 边框颜色/渐变 + emoji/透明PNG贴纸叠加,动物趴气泡=贴纸锚定顶边半重叠;**每条消息气泡都带**(用户明确,不是每轮第一条);实施等用户说"构建"再动(构思期不动代码)
- [2026-11-04] **二期拍板进阶版架构**:发现聚合页(两层收纳,后续功能全进发现页)+朋友圈/打卡独立页面+助手四工具;蓝图全文见 .zcode/memory/phase2-blueprint.md(含底座探明事实/DDL模板/实现清单A-G/不做清单),新窗口按此直接开工
- [2026-11-05] **边框美化"编辑对象"语义**:只决定编辑哪侧(助手/用户/两侧同时),两侧始终各自渲染自己的配置;"两侧同时"=改动同步写入两侧——用户纠正过"统一配置"的错误理解,别再犯
- [2026-11-07] **数据库迁移只做纯增量,升级前必提醒备份** — 用户明确担心大更新弄坏数据;新表只 CREATE/加列不碰旧数据;数据安全是长期约束
- [2026-11-07] **凡 UI 改动先出 HTML 预览给用户确认再写代码** — 用户重申升级为硬规则(r200 主题迭代全程照此执行)
- [2026-11-07] **助手后台只互动不进聊天** — 社交通知轮 requireVisibleReply=false,只点赞评论不输出聊天消息;用户未答按推荐落地
- [2026-11-07] **双向互动** — 用户也能给助手的朋友圈/打卡点赞评论;评论提醒助手、点赞不提醒(防噪音)
- [2026-11-08] **心里话便签墙定稿方案A** — 双列瀑布+图钉+折角;便签纸色随主题(绿色主题=绿纸,用户点名"和打卡一样的绿色系")
- [2026-11-08] **称呼不预设** — 助手提示词不写死昵称,NAMING_GUIDE 让助手用自己平时对TA的称呼(用户不想被叫「用户」)
- [2026-11-08] **主题切换器=折叠下拉** — 各页顶栏 🎨 按钮下拉单选(收纳原则:选项收纳进下拉)
- [2026-11-08] **写完代码立即自查,不是构建前才查(用户两次纠正定稿)** — 每完成一个改动批次,当场执行自查并在回复里给出结论:①改动文件 import 完整性(协程 launch/composable 最易漏)②跨文件重命名/签名变更 grep 全部调用点③YAML/XML 只用 Edit 工具改,改完 file 验 UTF-8④Room/DAO 实体列与迁移注册一致性⑤新 API 用法对照 lessons.md 踩坑清单⑥括号/代码块平衡重读关键段 — 有错当场修,修完复查,然后才轮到预览/构建;CI 的 compileDistKotlin 步只是最后防线,不替代写完即查
- [2026-11-08] **评论回复语义=reply_to** — 顶层评论不显示「xx回复xx」,仅显式回复某条评论才显示;点评论行进入回复模式(输入框「回复xxx」);助手工具 reply_to 参数同规则,回复 assistant 时后台提醒
- [2026-11-08] **心里话三件套无条件授权** — 不依赖助手本地工具开关(社交套件门控也删),开关 UI 移除
- [2026-11-08] **顶栏社交入口常驻** — 地球图标点按下拉(发现/朋友圈/心里话/打卡),长按唤醒任务;showFeatureHub 废弃
- [2026-11-08] **版本号跟随构建** — versionCode=run_number/versionName=2.5.6-rN 工作流注入,根治覆盖安装无法确认
- [2026-11-08] **便签排列样式=顶栏折叠下拉** — 双列瀑布/单列时间线/三列紧凑,存 DisplaySetting.secretsLayout
