# 决策

- [2026-11-01] **生图功能停用,事故以"日常可用"结案** — 用户明确不再用生图;r176/r177 生图修复在库但未实测,重启生图前必须先用 gpt-image-2 试一张验证
- [2026-11-01] **每完成一段工作立即 commit+push** — 用户要求跨设备信息不断层,云端仓库是唯一载体(长期有效的工作指令)
- [2026-11-01] **构建完成后给实测过的最快下载链接(纯文本格式)** — 用户网络 GitHub 直连慢,镜像时效性强,每次现测现推
- [2026-11-02] **气泡样式精简拍板** — 删"玻璃风格"选择器只留"气泡材质";材质只留 默认/玻璃/水珠(磨砂/毛玻璃肉眼无差);气泡形状移入助手页每助手独立,全局页删选择器
- [2026-11-02] **气泡美化走边框贴纸方向,不改形状** — 边框颜色/渐变 + emoji/透明PNG贴纸叠加,动物趴气泡=贴纸锚定顶边半重叠;**每条消息气泡都带**(用户明确,不是每轮第一条);实施等用户说"构建"再动(构思期不动代码)
- [2026-11-04] **二期拍板进阶版架构**:发现聚合页(两层收纳,后续功能全进发现页)+朋友圈/打卡独立页面+助手四工具;蓝图全文见 .zcode/memory/phase2-blueprint.md(含底座探明事实/DDL模板/实现清单A-G/不做清单),新窗口按此直接开工
- [2026-11-05] **边框美化"编辑对象"语义**:只决定编辑哪侧(助手/用户/两侧同时),两侧始终各自渲染自己的配置;"两侧同时"=改动同步写入两侧——用户纠正过"统一配置"的错误理解,别再犯
- [2026-11-07] **数据库迁移只做纯增量,升级前必提醒备份** — 用户明确担心大更新弄坏数据;新表只 CREATE 不碰旧表;数据安全是长期约束
